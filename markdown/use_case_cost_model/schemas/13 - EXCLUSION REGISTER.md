# Exclusion Register Schema

## Purpose

Makes material exclusions explicit and reviewable.

## ID

`EXC-###`

## Fields

| Field | Required | Description |
|---|---:|---|
| Exclusion ID | Yes | Stable ID |
| Excluded Work / Cost / Capability | Yes | Exclusion |
| Reason | Yes | Basis |
| Source / Decision ID | Yes | SCP/DEC/ASM |
| Likely Cost-Bearing Organization | No | ORG |
| Potential Magnitude | No | Qualitative/range |
| Risk if Misunderstood | Yes | Decision risk |
| Recommended Treatment | Yes | Exclude / Optional / Sensitivity / Future cost |
| Status | Yes | Active/Superseded |

## Rules

- Necessary work should not be excluded merely because it lacks public evidence.
- Post-pilot costs may be excluded from pilot totals but shown separately.
